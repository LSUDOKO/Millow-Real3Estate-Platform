# Millow-Real3Estate-Platform

Package manager: npm.

## Commands

- dev: `npm run dev`
- build: `npm run build`
- test: `npm test`

## Layout

- `contracts/`
- `metadata/`
- `public/`
- `scripts/`
- `src/`
- `test/`

## Rules

- Run `npm test` before you say a change is done.
- Never commit secrets or `.env` files.
